# Cosmiq

Cosmiq is a cosmetics platform for Minecraft that lets players wear cosmetics, use emotes and play together in multiplayer.

This is the official public repository for Cosmiq. **Cosmiq is not open source**, so the mod's source code is not published here. This repository is for:

- **Translations:** the language files are in [`lang/`](lang). See [Contributing](CONTRIBUTING.md#translations).
- **Bug reports:** [open a bug report](../../issues/new?template=bug_report.yml).
- **Suggestions:** [open a feature request](../../issues/new?template=feature_request.yml).

Please read the [contributing guidelines](CONTRIBUTING.md) before you open an issue or pull request.
